## Wie ich arbeite

- **Erst der Zweck, dann der Code.** Ein Werkzeug, das eine Sache gut kann, ist mehr wert als eines, das vieles halb kann.
- **Keine Fremdaufrufe ohne Grund.** Wenn eine Seite verspricht, nichts nach draußen zu senden, dann prüft der Bauvorgang das auch nach.
- **Gestaltung ist kein Anstrich.** Abstand, Schrift und Farbe entscheiden mit darüber, ob jemand ein Programm versteht.
